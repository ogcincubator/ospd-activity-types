# OSPD Activity Types Register

Activity types specific to the OGC Open Science Persistent Demonstrator (OSPD), published as an
[OGC Building Blocks](https://ogcincubator.github.io/bblocks-docs/) register. It is a federated register of the
[Activity Types Register](https://github.com/ogcincubator/activity-type-register), which holds the generic activity
types: each type here specialises one of them (`skos:broader`).

- Persistent URIs: `https://w3id.org/ogc/ospd/activity-type/<slug>` (generic and specific types share the namespace)
- Blocks: *OSPD Activity Types Register* (catalog) and *OSPD specific activity types* (the concept scheme and the types, as Turtle)
- Data: uploaded to the OSPD Prez instance on build
- Review tables: [`docs/analysis`](docs/analysis)

See `SECURITY.md` and `USAGE.md` (from the bblock-template) for build and viewing instructions.
