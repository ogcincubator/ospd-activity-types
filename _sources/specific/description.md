# OSPD specific activity types

Activity types specific to OSPD: tool- and example-specific specialisations of the generic activity types. Each one points to
its generic parent with `skos:broader`; types still without a generic parent are pending classification.

This block has 65 activity types. Its data resource (`data.ttl`) is uploaded to the OSPD Prez instance when the register is built.
